# FastAPI-Tailwind-JS-SQLite_quizAPP
Practicing FastAPI, Tailwind CSS, Javascript, and using the SQLite database interface to create a quiz application for students. ChatGPT was used to help with the project structure, debugging, and some styling. No code was just copy/pasted.
SET UP Environment:
    in main project directory create a virtual environment:
        python -m venv venv 
        source venv/bin/activate
    install project dependencies:
        pip install fastapi[all] uvicorn sqlalchemy pydantic alembic python-multipart
